# Radio Jugoseo

Proyecto académico desarrollado para la asignatura
Desarrollo Fullstack II.

Radio Jugoseo es una plataforma web orientada a una
radio digital, que integra la gestión de usuarios,
programación radial y una tienda en línea.

## Tecnologías

- Frontend: React y Vite
- Backend: Java 17 y Spring Boot
- Persistencia: MySQL y Spring Data JPA
- Seguridad: Spring Security y BCrypt
- Control de versiones: Git y GitHub

## Arquitectura

El proyecto utiliza una arquitectura basada en
microservicios independientes.

Cada microservicio cuenta con su propio repositorio,
base de datos y responsabilidades específicas.
